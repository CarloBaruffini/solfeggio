# Changelog

All notable user-visible changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Changed

- Rewrote the app in React + TypeScript with the same features as the prototype.
- The music font and UI fonts are bundled with the app: no external CDN is needed.

### Added

- Installable app (PWA) that works offline after the first visit.
- Automatic deployment to GitHub Pages.

## [0.1.0] - 2026-10-30

### Added

- Single-file prototype: random notes in treble, bass or alto clef, 12-key piano
  (mouse, touch or computer keyboard), optional ledger lines and accidentals,
  synthesized sound, statistics.
