# Glossary (Italian ↔ English)

The UI is in Italian; code and docs use the English terms below.

| Italiano                                    | English                          | In code                                                |
| ------------------------------------------- | -------------------------------- | ------------------------------------------------------ |
| Pentagramma                                 | Staff (stave)                    | `Stave`, `StaffView`                                   |
| Rigo / linea                                | Staff line                       | —                                                      |
| Spazio                                      | Space                            | —                                                      |
| Taglio addizionale                          | Ledger line                      | `ledgerLines`                                          |
| Chiave di violino (Sol)                     | Treble clef (G clef)             | `'treble'`                                             |
| Chiave di basso (Fa)                        | Bass clef (F clef)               | `'bass'`                                               |
| Chiave di contralto (Do in terza)           | Alto clef (C clef)               | `'alto'`                                               |
| Doppio pentagramma / sistema per pianoforte | Grand staff                      | —                                                      |
| Nota                                        | Note / pitch                     | `Pitch`                                                |
| Nome della nota (Do, Re, Mi…)               | Solfège name                     | `NamingSystem 'solfege'`                               |
| Nome anglosassone (C, D, E…)                | Letter name                      | `NamingSystem 'letter'`                                |
| Alterazione                                 | Accidental                       | `Accidental`                                           |
| Diesis (♯)                                  | Sharp                            | `1`                                                    |
| Bemolle (♭)                                 | Flat                             | `-1`                                                   |
| Bequadro (♮)                                | Natural                          | `0`                                                    |
| Ottava                                      | Octave                           | `octave` (scientific pitch notation: Do centrale = C4) |
| Do centrale                                 | Middle C (C4, MIDI 60)           | —                                                      |
| Classe di altezza (nota senza ottava)       | Pitch class (0 = C … 11 = B)     | `pitchClass()`                                         |
| Tasto bianco / nero                         | White / black key                | —                                                      |
| Durata (semibreve, minima, semiminima…)     | Duration (whole, half, quarter…) | —                                                      |
| Metronomo                                   | Metronome                        | —                                                      |
| Spartito                                    | Score / sheet music              | —                                                      |
| Lettura a prima vista                       | Sight-reading                    | —                                                      |
